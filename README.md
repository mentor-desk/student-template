# Student project

This repository is your project for the mentorship. Every week you work on the tasks in Mentor Desk.

## How to work

1. Create a branch for each task, for example `git switch -c week-1-set-up`.
2. Push the branch and open a pull request into `main`.
3. Link the pull request on the task in Mentor Desk, then send it for review.
4. The checks run on every pull request. Keep them green.
5. Your mentor reviews it. When the task is closed, the pull request is merged for you.

`main` is protected: you cannot push to it or merge into it yourself.
